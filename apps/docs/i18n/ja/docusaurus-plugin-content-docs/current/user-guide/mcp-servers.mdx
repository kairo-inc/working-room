# MCP サーバー

WorkingRoom は外部の [MCP (Model Context Protocol)](https://modelcontextprotocol.io/) サーバーに接続し、そのサーバーが提供する Tool をチャットで Agent が使えるようにします。たとえば、課題管理、データベース、社内サービスなどの Tool です。

MCP サーバーは個人ごとの設定です。追加したサーバーは自分にだけ表示され、自分のチャットでだけ使われます。同じテナントの他のユーザーには、サーバーもアクセストークンも見えません。

## 要件

- MCP サーバーは **Streamable HTTP** トランスポートに対応している必要があります。ローカルプロセスとしてのみ動作するサーバー（stdio）には対応していません。
- 認証は **アクセストークン** のみです。`Authorization` ヘッダーで Bearer トークンとして送信されます。MCP の OAuth 認可フローには対応していません。
- サーバーには、ブラウザからだけでなく、WorkingRoom のサーバーからアクセスできる必要があります。

## サーバーを追加する

1. **アカウント** ページを開き、**MCPサーバー** セクションを表示します。
2. **+** ボタンを選択します。
3. 次の項目を入力します。
   - **名前** — 英数字、`_`、`-` のみ、32 文字以内。自分のサーバーの中で重複できません。Agent から見える Tool 名の一部になります（例: `mcp__github__create_issue`）。
   - **URL** — サーバーのエンドポイント。`http://` または `https://` で始まる必要があります。
   - **アクセストークン**（任意） — 認証が不要なサーバーでは空欄のままにします。
4. **保存** を選択します。

保存すると、WorkingRoom はサーバーに接続して Tool の一覧を取得します。接続に失敗した場合はサーバーは保存されず、アクセストークンが拒否されたのか、サーバーに接続できなかったのかがエラーメッセージで表示されます。

一覧の各サーバーには、URL と取得した Tool の件数が表示されます。

## チャットで MCP の Tool を使う

有効にしたサーバーの Tool は、自分が開始するすべてのチャットで Agent が使えます。Tool を選ぶ必要はありません。組み込みの Tool と同じように、Agent がいつ使うかを判断します。

Tool の呼び出しに承認が必要かどうかは、サーバーがその Tool をどう説明しているかで決まります。

- サーバーが **読み取り専用** としている Tool は、承認なしで実行されます。
- それ以外の Tool（データを書き込む・削除する Tool や、サーバーが説明していない Tool を含む）は、承認が必要です。承認カードには、サーバー名、Tool 名、Agent が送ろうとしている入力が表示されます。

サブエージェントは、読み取り専用の MCP の Tool だけを使えます。サブエージェントの Tool 呼び出しを承認する人がいないためです。

:::note
Tool が読み取り専用かどうかは、MCP サーバー自身が申告するものです。信頼できるサーバーだけを追加してください。
:::

## サーバーを管理する

- **有効にする / 無効にする** — サーバーを削除せずに、一時的に Agent がその Tool を使えないようにします。
- **Toolを再取得**（円形の矢印のボタン） — サーバーの Tool の一覧を取得し直します。チャットの開始時にサーバーを待たなくて済むよう、WorkingRoom は Tool の一覧を保存しています。サーバー側で Tool が追加・削除・変更されたら再取得してください。
- **編集** — 名前、URL、アクセストークンを変更します。アクセストークンを空欄のままにすると現在のトークンが使われ続けます。消したい場合は **アクセストークンを削除する** をオンにします。URL やアクセストークンを変更すると、Tool の一覧も取得し直します。
- **削除** — サーバーとそのアクセストークンを削除します。

## トラブルシューティング

チャット中に MCP の Tool の呼び出しが失敗すると、Agent が原因と対処方法を伝えます。

| 問題                                 | 対処方法                                                                  |
| ------------------------------------ | ------------------------------------------------------------------------- |
| サーバーがアクセストークンを拒否した | アカウントページでサーバーを編集し、正しいアクセストークンを入力します。  |
| サーバーに接続できなかった           | サーバーが起動しているか、URL が正しいかを確認します。                    |
| サーバーに Tool が見つからなかった   | Tool の一覧が変わっているため、そのサーバーで **Toolを再取得** を選択します。 |

WorkingRoom は、サーバーへの接続を最大 10 秒、Tool の呼び出しの完了を最大 60 秒待ちます。
